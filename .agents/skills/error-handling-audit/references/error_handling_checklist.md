# Error Handling Checklist

Class key: `passive` = errors already captured. `bounded` = fixed malformed-input set per parameter, low-rate differentials. `authorized-only` = large enumeration, crash/exhaustion inputs, error-based extraction.

## Core checks (10)

| ID | Product | Check | Class | Safe verification |
|---|---|---|---|---|
| EH-001 | Errors | Verbose error messages with stack traces and file paths | bounded | error_probe.py signatures (Python, Java/Spring, .NET, Node, PHP, Ruby, Go) |
| EH-002 | Database | Database error disclosure with query information (SQL text, table/column names, driver errors) | bounded | error_probe.py quote/type variants; `db-query` and `sql-error` signatures; escalate to sqli |
| EH-003 | Versions | Framework or server version disclosure on error pages (Tomcat, Jetty, IIS, nginx, Apache, Django, Laravel, Spring Boot, Express) | bounded | error_probe.py version regexes on 4xx/5xx bodies and headers |
| EH-004 | Internal info | Internal IP, hostname, and filesystem path disclosure in errors | bounded | error_probe.py `internal-ip`, `fs-path`, internal hostname patterns |
| EH-005 | Crafted input | Error-based disclosure via crafted input: type confusion, quotes, nulls, arrays, objects, oversize, unicode, invalid encodings, missing params, wrong method or content type | bounded | error_probe.py full variant set per parameter |
| EH-006 | Enumeration | Different error responses reveal valid vs invalid input (username, email, ID, coupon, token, file) | bounded | error_probe.py `--enum --valid OWN --invalid RANDOM` (status, length, message, timing) |
| EH-007 | Error pages | Custom error pages missing; default server/framework pages shown (404, 403, 405, 500, 502) | bounded | error_probe.py default-page signatures on random path and malformed requests |
| EH-008 | Debug | Debug-mode error pages in production (Django yellow page, Werkzeug debugger, Laravel Ignition, Rails dev, Symfony, ASP.NET YSOD, Spring Whitelabel with trace) | bounded | error_probe.py debug signatures; see server-config-audit SMC-006 |
| EH-009 | API status codes | API returns 500 for client errors (malformed JSON, wrong types, missing fields) or 200 with error bodies; inconsistent codes | bounded | error_probe.py flags 5xx on client-side faults and 2xx with error payloads |
| EH-010 | GraphQL | GraphQL errors disclose schema, resolver paths, exception classes, stack traces (`extensions.exception.stacktrace`), SQL | bounded | error_probe.py `--graphql`; graphql-audit GQL-009 and GQL-010 |

## Crafted input catalog (error_probe.py)

| Variant | Example value | Aims at |
|---|---|---|
| single quote | `'` | SQL/parser errors |
| double quote | `"` | JSON/SQL/template errors |
| backslash | `\` | escaping errors |
| template | `{{` and `${` | template engine errors |
| null byte | `%00` | C-string and path errors |
| array | `param[]=1` / JSON `[1]` | type confusion |
| object | `param[x]=1` / JSON `{"a":1}` | type confusion, ORM errors |
| long string | 5000 × `A` | length validation, buffer errors |
| negative / huge number | `-1`, `99999999999999999999` | integer parsing, overflow |
| non-numeric | `abc` for numeric | casting errors |
| float / exponent | `1e309`, `NaN` | float parsing |
| unicode | `￿`, `%C0%AF`, RTL override | encoding errors |
| invalid percent-encoding | `%`, `%zz` | URL decoder errors |
| empty / missing | `param=` and parameter removed | null handling |
| wrong method | PUT/PATCH/FOO | routing/405 handling |
| wrong content type | `text/xml` with JSON body | parser selection |
| malformed JSON | `{"a":` | JSON parser errors |
| boolean / null | `true`, `null` | type confusion |

## Default error page signatures

| Product | Signature |
|---|---|
| Apache | `<title>404 Not Found</title>` + `Apache/` in `<address>` |
| nginx | `<center>nginx</center>`, `<center>nginx/1.` |
| IIS | `IIS 10.0 Detailed Error`, `HTTP Error 404.0 - Not Found`, `Server Error in '/' Application` |
| Tomcat | `Apache Tomcat/`, `HTTP Status 404 – Not Found` with `Type Status Report` |
| Jetty | `Powered by Jetty://` |
| Express | `Cannot GET /`, `Cannot POST /` |
| Django | `Page not found (404)` with `Request Method:` and `Using the URLconf` (debug) |
| Flask/Werkzeug | `The requested URL was not found on the server. If you entered the URL manually` |
| Spring Boot | `Whitelabel Error Page` |
| Laravel | `404 \| Not Found` default, Ignition pages |
| Rails | `The page you were looking for doesn't exist.` |
| ASP.NET Core | `Developer Exception Page`, `An unhandled exception occurred while processing the request` |
| Cloudflare / AWS ALB / CloudFront | `cloudflare` error templates, `502 Bad Gateway` from `awselb/2.0`, `Generated by cloudfront` |

## Expected API status codes

| Situation | Expected |
|---|---|
| Malformed JSON, wrong types, missing required field | 400 or 422 |
| Not authenticated / not authorized | 401 / 403 (or 404 to hide existence) |
| Resource not found | 404 |
| Method not allowed | 405 |
| Unsupported media type | 415 |
| Rate limited | 429 |
| Server fault only | 500 / 502 / 503 |
