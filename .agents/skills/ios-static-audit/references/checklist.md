# iOS Static Analysis checklist

Generated by `.agents/skills/ios-app-audit/scripts/build_ios_checklists.py` from the source checklist. Edit the source and rebuild; do not edit this table. Track status with `ios_checklist.py`.

Class key: `passive` = read the IPA only. `bounded` = read-only on the test device, its backup, or in-scope hosts. `authorized-only` = active, needs written approval for that check. `not-tested` = OS or platform behaviour, recorded only.
